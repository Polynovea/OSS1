# Support

Polynovea CMS is community-supported open-source software.

## Ask for help

Before opening an issue, check the README, local quickstart, operations runbooks and existing issues. Use a GitHub Discussion for usage and architecture questions when Discussions are enabled. Use an issue for reproducible defects and feature proposals.

Include the application version or commit, deployment profile, Node.js and PostgreSQL versions, relevant redacted logs, reproduction steps and expected behavior. Never include credentials, tokens, private content or customer data.

## Security issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Support boundary

Maintainers cannot guarantee response times or provide private operational support through public issues. Production operators remain responsible for infrastructure security, backups, recovery testing, monitoring and upgrades.
