# Roadmap

The roadmap prioritizes accessible governed content workflows, deterministic operational intelligence and an OSS runtime that users can operate without Polynovea-owned infrastructure. No item authorizes bypassing workspace isolation, approval policy or the deterministic controller.

## Release-readiness work in progress

- Keep the recorded clean-install certification current as the supported Supabase-compatible runtime evolves, including authentication, workspace bootstrap, content, media, preview, workflow, delivery, API/SDK/CLI, restart and persistence verification.
- Build and certify a provider-neutral data/auth seam before advertising turnkey direct generic PostgreSQL, RDS/Aurora or Azure PostgreSQL runtime support.
- Expand the S3-compatible storage adapter beyond the R2 reference configuration and certify each supported provider.
- Re-run security and deployment evidence against the final release candidate.

## Delivered engineering foundations

Phases 8–11 code, migrations, admin surfaces and certification suites are present for localization/releases, assurance/discoverability, durable delivery operations, and search/analytics/content health. Phase 13 release engineering, MCP and extension foundations are present. These are repository/readiness statements, not a statement that a public package release has been published.
